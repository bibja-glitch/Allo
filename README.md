# АЛЛО, РОУД — Telegram Bot

Минималистичная игра для двух друзей внутри **Telegram**. Когда один друг не поднимает телефон, второй отмечает пропуск: бот отправляет моноширинное сообщение `<pre>` и покадрово анимирует через `editMessageText` одну из 34 ASCII-сцен, завершает экраном `F A T A L I T Y !`, удаляет временную анимацию и оставляет компактную карточку с актуальным счётом.

## Возможности

- **34 ASCII-сцены** (`32×11` под мобильные экраны) с автоматическим зеркалированием направления удара.
- **Быстрый режим анимации** (5 ключевых кадров вместо 8) в настройках пары.
- **Перезвоны и сводка дуэли** (`/callback`, `/stats`) — индекс ответов, лидер недели и история событий.
- **Режим превью** (`/scenes`) — просмотр случайной ASCII-сцены без изменения счёта.
- **Навигация в одном сообщении** — кнопки `Счёт`, `История`, `Сводка`, `Настройки` редактируют карточку на месте, не засоряя чат.
- **Визуальный профиль бота при деплое** — `/api/telegram/setup` и `npm run bot:deploy` автоматически загружают минималистичный аватар (`setMyProfilePhoto`), описание (`setMyDescription`), короткое описание (`setMyShortDescription`) и чистый список команд (`setMyCommands`).

## Настройка и деплой на Vercel

1. Создайте бота у `@BotFather` и получите `TELEGRAM_BOT_TOKEN`.
2. Создайте базу в Upstash Redis (`UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`).
3. Добавьте переменные окружения в проект Vercel (см. `.env.example`).
4. После деплоя выполните настройку webhook и визуального профиля бота:

```bash
curl -X POST "https://your-project.vercel.app/api/telegram/setup" \
  -H "x-setup-secret: YOUR_TELEGRAM_WEBHOOK_SECRET"
```

Или локально после настройки `.env`:

```bash
npm run bot:deploy
```
